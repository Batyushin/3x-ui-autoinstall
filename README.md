# 3x-ui Auto-Installer (с самоподписанным SSL)

Этот скрипт полностью автоматизирует процесс установки официальной панели [3x-ui](https://github.com/mhsanaei/3x-ui) и избавляет от необходимости вручную настраивать HTTPS для доступа по IP-адресу.

## 🚀 Установка (One-liner)

Подключитесь к вашему серверу по SSH (от имени `root`) и выполните всего одну команду:

```bash
bash <(curl -Ls [https://raw.githubusercontent.com/Batyushin/3x-ui-autoinstall/refs/heads/main/install.sh](https://raw.githubusercontent.com/Batyushin/3x-ui-autoinstall/refs/heads/main/install.sh))

## ⚙️ Что делает скрипт:

* Устанавливает зависимости (`curl`, `openssl`, `sqlite3`).
* Устанавливает актуальную версию 3x-ui (соглашаясь на дефолтные настройки).
* Генерирует SSL-сертификат (самоподписанный, сроком на 10 лет), привязывая его к внешнему IP-адресу вашего сервера.
* Интегрирует сертификат — напрямую вносит пути к `.crt` и `.key` файлам в базу данных SQLite (`x-ui.db`).
* Перезагружает панель, чтобы она сразу была доступна по безопасному протоколу `https://`.

## 🔐 Доступ после установки

Сразу после завершения работы скрипта панель будет доступна по адресу:

* **URL:** `https://<IP_ВАШЕГО_СЕРВЕРА>:2053`
* **Логин по умолчанию:** `admin`
* **Пароль по умолчанию:** `admin`

> **Внимание:** Так как сертификат генерируется локально (самоподписанный), браузер выдаст предупреждение о том, что подключение не защищено.
> 
> * **В обычных браузерах:** Нажмите «Дополнительные настройки» -> «Все равно перейти на сайт».
> * **В Google Chrome:** Если кнопки перехода нет, просто кликните в любое пустое место на странице с ошибкой и наберите на клавиатуре (вслепую) `thisisunsafe` — панель откроется.
